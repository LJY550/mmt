画像素画最愉快的地方在于：你不需要会画画，你只需要会**填格子**。

## 工具

- 一个文本文件（用来写网格）
- Python + Pillow（把网格变成 PNG）
- 一个放大倍率（比如 8 倍，方便肉眼检查）

## 第一步：定义调色板

黑白主题只需要三种符号：

| 符号 | 含义 | 结果 |
| --- | --- | --- |
| `#` | 实心黑 | 不透明的黑色像素 |
| `o` | 挖空白 | 不透明的白色像素（做眼睛、胸口） |
| `.` | 透明 | 完全不画 |

## 第二步：画一个坐着的猫

猫头用**轮廓线**画，不涂满——耳朵是两个三角形边框，眼睛是两条短横线，鼻子和嘴占中间三格：

```
....#..........#...     ← 耳尖
...#.#........#.#..
..#...#......#...#.
.#......####......#     ← 头顶轮廓
#...####....####...     ← 眼睛（4 格横条）
#....##......##....     ← 瞳孔
.#....#..##..#....#     ← 鼻子（##）和嘴角
..###..........###.
.....##########.....     ← 下巴
```

**线条圆润的关键是切角**：凡是 45° 转折的地方，让阶梯等差过渡（`4 → 3 → 2`），
不要让两段直线在角上硬碰硬。轮廓风的猫比剪影风更"轻盈"，但要求线条闭合——
断掉一格，整个头就会散架。

然后接身体。线稿身体只有左右两条轮廓线、一条底线和两只脚：

```
....##........##....     ← 肩
...#............#...
..#..............#..
..################..     ← 底
..###..........###..     ← 两只脚
```

最后是尾巴。尾巴用一串 1px 的点沿曲线摆放，我用坐标单独补：

```python
CAT_SIT_TAIL = [(18, 22), (19, 22), (19, 21), (19, 20),
                (19, 19), (18, 18)]
```

尾巴从屁股右侧伸出，向上翘起来——这条弧线决定整只猫的"精神状态"。

## 第三步：导出 PNG

```python
from PIL import Image

def build(rows, width, height, extras=None):
    img = Image.new("RGBA", (width, height), (0, 0, 0, 0))
    px = img.load()
    for y, row in enumerate(rows):
        for x, ch in enumerate(row):
            if ch == "#":
                px[x, y] = (0, 0, 0, 255)
            elif ch == "o":
                px[x, y] = (255, 255, 255, 255)
    for x, y, ch in extras or []:
        px[x, y] = (0, 0, 0, 255) if ch == "#" else (255, 255, 255, 255)
    return img
```

## 第四步：三个变体

同一只猫换个姿势，其实就是改几行：

- **走路的猫**：身体横过来，头移到右侧，四条腿错开，尾巴在左边甩
- **睡着的猫**：缩成一团，眼睛变成一条短横线（闭眼），尾巴卷到身前
- **猫脸**：只取头部，当成站点 logo

## 第五步：让它眨眼

眨眼动画只需要第二帧：把眼睛的**上排涂黑，下排白线保留**，睁眼块（2×2）就变成了眯眼线（2×1）。

```python
def close_eyes(rows, eyes):
    """eyes: [(y_top, y_bottom, x0, x1), ...]"""
    rows = [list(r) for r in rows]
    for y0, _y1, x0, x1 in eyes:
        for x in range(x0, x1 + 1):
            rows[y0][x] = "#"
    return ["".join(r) for r in rows]
```

前端把两帧叠在一起，用 CSS 定时切换——注意用 `steps(1, end)`，
让透明度**跳变**而不是淡入淡出，否则像素猫会变成"渐变猫"，直接开除像素籍：

```css
.blink-closed {
  position: absolute;
  inset: 0;
  opacity: 0;
  animation: cat-blink 5.2s steps(1, end) infinite;
}
@keyframes cat-blink {
  0%, 90% { opacity: 0; }
  91%, 96% { opacity: 1; }
  97%, 100% { opacity: 0; }
}
```

每 5.2 秒眨一次，闭眼约 0.36 秒——和真猫的频率差不多。

## 常见翻车点

1. **眼睛不对称** —— 16 宽的网格里，列 `c` 的镜像列是 `15 - c`，眼睛放 4、5 列，另一只就要放 10、11 列
2. **抗锯齿** —— 放大时一定要 `Image.NEAREST`，网页里一定要 `image-rendering: pixelated`
3. **细节太多** —— 16×16 一共 256 格，超过 6 个细节元素就会糊成一团。删，不要加

> 当你觉得"好像还缺点什么"的时候，正确答案通常是再删两格。

本站 `public/sprites/` 下的全部素材都来自这个流程，脚本在 `scripts/gen_sprites.py`。
